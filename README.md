# ☕ Coffee Shop Sales Analysis Project
Tools Used: MySQL, Power BI
Project Type: Exploratory Data Analysis & Dashboard Reporting
Domain: Retail | Sales | F&B

🔍 Project Overview:
I conducted an end-to-end analysis of a coffee shop's transactional data using MySQL for data cleaning and complex querying, and Power BI for building an interactive dashboard to deliver actionable business insights.

🛠 Key Steps:
Data Cleaning (MySQL):

Parsed and reformatted date and time fields using STR_TO_DATE().

Modified data types for consistency.

Removed inconsistencies to prepare the dataset for analysis.

Data Analysis (MySQL):

Calculated total sales, order counts, and quantities sold by month.

Performed month-over-month (MoM) comparisons to track performance trends.

Segmented sales by:

Weekday vs Weekend

Store location

Product categories and top-selling products

Daily and hourly breakdowns

Dashboard Visualization (Power BI):

Created a dynamic dashboard for June 2023, showing:

📈 Total Sales: $166K (+6% MoM)

📦 Total Orders: 35,352

🧾 Quantity Sold: 50,942 units

🔁 Daily trends with average line

📍 Location-wise sales comparison

⏰ Hourly heatmap for peak business hours

📊 Top 10 best-selling products and product categories

✅ Key Insights:
Weekdays contributed to 73% of the total monthly revenue.

Hell’s Kitchen was the top-performing store location.

Friday and Saturday were the highest revenue-generating days.

Barista Espresso and Brewed Chai Tea were top-selling items.

Sales peaked between 8 AM to 10 AM, suggesting strong morning demand.
